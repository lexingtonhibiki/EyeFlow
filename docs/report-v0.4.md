# v0.4 变更报告：自定义提示音、严格模式壁纸、长休息延后、更新检查评估与 GitHub 迁移

> 日期：2026-09-10 · 用户需求六项 + 自主 UX 改进 + 更新检查“合不合适”评估 + GitHub 邮箱隐私处理。
> 执行方式：2 个并发 Agent（自定义音频 / 壁纸与裁剪预览）+ 主 Agent 集成（调度核心、设置窗、托盘、更新检查、安装器、文档）。

## 1. 长休息允许延后 + 延后次数颜色化

- `core.rs`：延后规则改为“短休息与长休息每回合各可延后一次”；长休息延后后到点仍是长休息（用屏累计不清零），跳过仍是 10 分钟再提示。ADR-0003 已追加修订说明：底线从“禁止延后”改为“再提示机制”守住。
- 预告面板“延后 N 分钟”对长休息启用，悬停提示“长休息也可延后一次；到点后仍是长休息”。
- 设置窗“现在”卡片：完成（绿）/ 跳过（红）/ 延后（0 灰 → 1~2 橙 → ≥3 红）分色；托盘 tooltip 有延后时附带次数；托盘菜单新增只读统计行“今日休息 N 次 · 跳过 X · 延后 Y”。
- 单元测试 `long_break_after_accumulated_screen_time_can_be_postponed_once` 覆盖：可延后一次 → 同回合不可再延后 → 跳过后 10 分钟再提示 → 完成后累计清零。

## 2. 安装器：桌面快捷方式勾选

- NSIS 新增 nsDialogs 自定义页“安装选项”，复选框“在桌面创建 EyeFlow 快捷方式”默认勾选；静默安装（`/S`）沿用默认值。
- 卸载器同步删除 `%USERPROFILE%\Desktop\EyeFlow.lnk`，保持零残留。

## 3. 自定义提示音（Agent A）

- 格式：wav / mp3 / ogg(vorbis) / flac / m4a / aac —— 对应 rodio 0.22 的 `wav` / `mp3` / `vorbis` / `flac` / `mp4` 解码特性（wma 不支持，界面已注明）。
- 时长上限 5 分钟：选择文件时 `probe_custom` 立即校验（存在 / 可解码 / 时长），错误中文提示；时长优先读容器元数据，缺失时逐样本计数并在超限 +1 秒时提前退出，避免长时间解码。
- 播放：`Decoder` 流式解码 → `take_duration(300 s)` 兜底截断 → `Player::connect_new(mixer)` + `set_volume` + `detach()`，**不整包载入内存**（5 分钟立体声解码后约 100 MB，必须流式）。音量沿用“提示音音量”滑条；“提示音时长”对自定义音频不循环（按文件本身播放一次，界面已注明）。
- 播放失败（文件被删、损坏）自动回退默认风铃并写日志。
- 测试 4 项：不存在路径 / 手写 1 s WAV 时长校验 / 2 s WAV 超限报错 / 随机字节 mp3 报“无法解码”。

## 4. 严格模式自选背景 + 自适应 + 裁剪预览（Agent B）

- 格式：png / jpg / webp / bmp / gif（`image` crate，仅启用这几种解码器控制体积）。
- 自适应三种：铺满裁剪（Cover，等比放大居中裁掉超出）/ 完整显示（Contain，等比缩放留暗边）/ 拉伸（Stretch）。裁剪数学 `crop_uv` 为纯函数，7 个单元测试覆盖 16:9↔4:3 互裁与留边、恒等、零尺寸不 panic。
- **实时预览**：设置窗内 16:9 预览框按同一套 `crop_uv` 绘制，切换自适应方式即时更新，悬停显示原图尺寸；这就是用户“裁剪时的预览”。
- 内存：最长边 > 2560 px 自动等比缩小后再上传纹理；纹理随 UI 会话生命周期释放（会话结束即释放，不常驻）。
- 可读性：图片上叠 ~43% 暗色蒙层，倒计时与贴士文字保持浅色。

## 6. “自己检索有没有最新版本”——合不合适？

**结论：合适，但必须 opt-in（默认关闭）+ 只读 + 不下载**。理由：

- 反方：README 一直承诺“纯本地、无网络”；后台工具悄悄联网会侵蚀这份信任，且 GitHub API 会记录来源 IP。
- 正方：护眼提醒依赖长期使用，用户不会主动去 Releases 页看更新；对开源小工具，版本号比对是零风险的最小实现。
- 折中实现：设置 → 系统 复选框“启动时检查更新”，默认**关闭**；开启后每 24 小时至多请求一次 `api.github.com/repos/lexingtonhibiki/EyeFlow/releases/latest`（10 秒超时、固定 User-Agent），只比对 tag 与当前版本，结果只显示在设置窗（有新版本 → 链接到发布页），**不下载、不安装、不弹窗**；“立即检查”按钮可手动触发。README 隐私章节同步改为“默认不联网；唯一可选联网功能是更新检查”。
- 被否决的做法：自动下载安装包（涉及未签名 exe 与 SmartScreen，且违背“用户可控”）；启动时无条件检查（违背隐私承诺）。
