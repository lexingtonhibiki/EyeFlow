# EyeFlow v0.7.4 — Windows / macOS / Linux

<!-- release-ready: v0.7.4 -->

## 主要变更 / Changes

- 拆分共享提醒核心和桌面适配层，新增 Linux 与 macOS 桌面构建；三个平台并非功能完全对等。
- 改进 Windows 音频设备恢复，以及设置窗口、休息弹窗打开时的托盘退出路径。
- 更新 `rustls-webpki` 至 0.103.16、`webpki-roots` 至 1.0.10。
- Linux X11 使用真实空闲、全屏和会话观测；缺失、失败或过期的读数会暂停自动提醒，不伪造安全状态。
- macOS 提供真实空闲观测和默认关闭的**兼容自动提醒**。用户须在设置中明确开启，接受无法保证锁屏/全屏避让的限制；未知或过期的空闲数据仍不能启动自动提醒。
- 增加系统 CJK 字体发现、非 Windows 可见主窗口、平台配置目录及逐目标第三方许可文件。

Shared reminder logic, native desktop backends and target-specific packages are included. Platform capabilities differ; the limitations below are part of this release's support scope.

## 下载与支持范围 / Packages and support

| 系统 | 安装包 | 支持边界 |
| --- | --- | --- |
| Windows 10/11 x64 | NSIS 安装器、便携 ZIP | 未代码签名；便携包包含许可证及第三方声明。 |
| Ubuntu 24.04 amd64 | DEB | 增强检测面向 GNOME/KDE X11。Wayland 仅提供基础手动界面，不支持自动空闲检测或原生全局快捷键。 |
| macOS 15+ Apple Silicon | arm64 DMG | 未 Developer ID 签名、未公证；自动提醒默认暂停，需明确开启兼容模式。 |
| macOS 15+ Intel | x86_64 DMG | 与 Apple Silicon 相同的能力和签名限制。 |

- Linux/macOS 尚未实现开机自启，相关设置明确禁用。
- macOS 锁屏/全屏检测不被声明为可靠支持；兼容模式不会把运行失败、权限不足或失效数据当作正常数据。
- macOS Gatekeeper、Windows SmartScreen 可能阻止未签名软件启动；本发布不建议关闭系统安全保护。
- 配置与日志路径、桌面环境限制见[平台说明](https://github.com/lexingtonhibiki/EyeFlow/blob/v0.7.4/packaging/PLATFORM-NOTES.txt)。

## 验证范围 / Validation scope

- 版前代码基线的[四目标 CI](https://github.com/lexingtonhibiki/EyeFlow/actions/runs/39919883276)覆盖 Windows、Linux、macOS arm64 与 x86_64 的构建和测试，以及实际包组装、校验和、许可内容与构建来源检查。正式版本切换仅调整版本和发行元数据；发行前还须通过该版本提交的 CI。
- Linux 隔离 Xvfb 中验证真实空闲时间增长、输入后的重置，以及根窗口、设置和手动休息弹窗的生命周期。它不等于真实 GNOME/KDE 锁屏、唤醒或 Wayland 验收。
- macOS 验证可见窗口及与菜单共用的设置、手动休息、正常退出路径。生命周期控制仅在独立测试构建中启用；发行二进制使用默认特性，不包含测试控制入口。这不等于实际鼠标点击托盘菜单或硬件音频验收。
- Windows 曾在软件 OpenGL、关闭声音的云端环境验证双窗口托盘退出；正式候选 CI 再次检查相应路径。用户确认过较早测试包拔插音频设备后有声音，**没有对后续退出修复包做真机复测**。
- 四份第三方声明按锁定依赖收集并核对；系统 Noto/PingFang 等字体不被复制，egui 内嵌字体的许可随包提供。

No claim is made that every desktop or hardware combination was manually tested. Automated GUI checks, build checks and user feedback are distinguished above.

## 发行完整性 / Distribution integrity

发布流程要求 tag、Cargo 版本和包元数据一致，四个目标构建全部成功、五个程序包及各自 SHA256 齐全后，才公开 Release。上传后会回读资产并比对字节；不会公开仅有部分平台的成功产物。

随包的 `LICENSE`、`THIRD_PARTY_NOTICES.txt` 及 Linux/macOS `BUILD_INFO.json` 提供许可与来源信息。更新配置会继续沿用平台上的既有配置目录；升级前可自行备份该目录。
