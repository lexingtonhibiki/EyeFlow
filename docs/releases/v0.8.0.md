# EyeFlow v0.8.0 — 休息设置与深浅主题

## 新增与修复

- 状态页可直接配置短休息（10–600 秒）与长休息（1–60 分钟），明确显示时长。旧配置的非整分钟时长在未编辑时不会被截断。
- 增加跟随系统、浅色、深色主题，选择自动保存并在重启时恢复。非法主题字段仅回退跟随系统，不重置其他休息或声音设置。
- 调整两种主题下的语义文本颜色，补充对比度回归。
- 自动进入休息时走开始提示音路径；重复点击立即休息不会重复播放开始提示音。尊重已有静音和开始提示音开关，不擅自打开声音。

## 验证及限制

- 本版代码包含 DS Flash 实作及协调 AI 修正，独立复核同样由 AI 完成，不宣称用户手写或人工审阅。
- 发行前要求本版 Windows/Linux/macOS CI，以及 Windows 原生点击、配置保存重启、独立休息窗验收通过。具体结果和链接待最终提交补入。
- 云端 GUI 使用软件 OpenGL 和静音配置，不能证明真实扬声器、耳机、蓝牙或音频切换表现；系统主题选择持久化测试不等于验证所有系统外观切换。
- 保留 v0.7.4 的平台边界：Windows 未代码签名；macOS 未签名/公证，兼容自动提醒需明确开启；Linux Wayland 不支持自动空闲检测或原生全局快捷键。请勿关闭系统安全保护。
- 当前保存失败时状态提示的既有局限未在本轮修复；本版保存/重启测试覆盖可写正常配置目录，不声称覆盖磁盘故障。

发布流程须校验版本、tag、五个安装/便携包及 SHA256，上传后回读验证再公开。未全部通过不发布。
