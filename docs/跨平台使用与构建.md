# EyeFlow 跨平台开发预览：使用与构建

这份代码保留 Windows 原版，新增共享 Rust 核心、Android 原生客户端、iOS 原生客户端和桌面前台计时预览。不是五个平台功能已完全相同的正式发行版。

## Android 测试 APK

历史最近已构建测试 APK 为 0.3.0（versionCode 4）。2026-10-16 的后续实时撤回修复仅交付源码与补丁，不附新 APK，不能把历史 APK 当作含修复版本。支持 Android 8.0（API 26）以上，包含 ARM64 手机和 x86_64 模拟器架构。安装前请确认来源是你自己的这份项目构建；本次没有替你安装到设备，也没有授予系统权限。

首次打开：

1. 在应用说明后主动开启「使用情况访问权限」。
2. 选择要关注的阅读、短视频等 App；只读前后台包名事件，不读取文字、视频内容或屏幕画面。
3. 允许通知，手动开始护眼会话。系统会显示可停止的静音运行状态通知。
4. 只有所选 App 在前台且屏幕已解锁时累计用屏。锁屏、未选 App、撤销权限时暂停累计并撤下休息提醒。
5. 未选 App、权限中断或未知间隔只暂停并保留待休息状态，不算休息。已证实连续锁屏达到短休时长（默认 30 秒）才重排短周期，达到长休时长（默认 15 分钟）才清除长周期用屏负担。短锁屏后续接；切换两个目标 App 不重置。
6. 提醒出现不等于完成休息。继续使用目标 App 不会靠通知倒计时自动获得休息完成记录；可主动进入应用内自愿休息，或通过已观察到的锁屏休息。应用不验证用户眼睛朝向。

用户可以延后、跳过、暂停或结束。应用不申请联网、无障碍或屏幕录制权限。0.3.0 仅在用户独立同意并手动开启后申请悬浮窗权限，用于最多10秒的小卡。厂商省电、系统强停、通知设置和系统投递时序仍需实机检验。默认仍为渐进通知，不自动全屏；小卡设计见 `docs/mobile-progressive-reminders.md`。本次源码修复与验证限制见 `docs/verification/android-live-revocation-2026-10-16.md`。

### Android 自行构建

准备 JDK 17、Android SDK Platform 35、Build Tools 35.0.0、NDK 27、CMake 3.22.1、Rust stable 与 cargo-ndk。按官方安装要求接受对应许可。Gradle 8.11.1 wrapper 已带下载校验和，不需要单独安装 Gradle。

从项目根目录执行（bash 环境）：

```sh
export ANDROID_HOME=/你的/Android/Sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.0.12077973"
cargo install cargo-ndk --locked
cd mobile/android
./build-rust.sh
./gradlew :app:assembleDebug :app:lintDebug
```

APK 输出：`mobile/android/app/build/outputs/apk/debug/app-debug.apk`。如在 Windows 构建，设置对应环境变量，Rust 库构建脚本可在合适的 bash 环境中运行，Gradle 可用 `gradlew.bat`。请勿把本地 SDK 路径、签名私钥或工具缓存提交到仓库。

## iPhone / iPad

提供 SwiftUI 自愿前台计时和休息界面，不代表可检测其他 App 的连续使用。

- 旧预览的每日累计用量入口与自动遮罩已停用，因为它不符合连续使用的需求。
- 启动时停止旧监测并清除 EyeFlow 自己的遗留遮罩，不触碰其他 App 的限制。
- 不发后台或锁屏休息通知。
- iOS 跨 App 连续用眼、短锁屏续接、足够长锁屏重置，目前没有完成可验证的受支持实现；不能把每日累计、延迟回调或自己界面的前台计时包装成该功能。
- 未来若有受支持的准确触发条件，遮罩仍须用户显式开启，默认关闭；当前不提供无效触发的自动遮罩。

需要 macOS、Xcode、Rust、XcodeGen。修改主应用和扩展的 bundle ID、App Group 标识，配置你自己的签名团队。保留的 Screen Time 扩展工程若要分发还需要 Apple 对主应用和扩展的 Family Controls 授权；这不会使当前不支持的连续监测自动可用。

```sh
./mobile/ios/scripts/build-core.sh
cd mobile/ios
xcodegen generate
open EyeFlow.xcodeproj
```

本次 Linux 云端没有 Xcode，因此没有生成 IPA，也没有完成 iOS 设备验收。具体检查表见 `mobile/ios/README.md`。

## Windows / macOS / Linux

Windows 原版代码保留；本次没有重新发布 Windows 安装器。`desktop/portable` 是可跨桌面系统编译的前台会话预览：仅在自身窗口活动时计时，保留共同的休息状态机和本地快照。目前不具备原 Windows 程序的系统托盘、全局键盘心流与全屏检测，不能当作 macOS/Linux 完整后台版。

```sh
cargo run --manifest-path desktop/portable/Cargo.toml
```

## 验证和源码

`docs/cross-platform-verification.md` 记录已执行和未执行项目。`scripts/verify-portable.sh` 运行共享核心及 C ABI 检查；`mobile/android/tests/run-host-tests.sh` 运行 Android 计时策略/JNI 联调。通过编译和静态检查不等于已经做过真机画面或后台行为验收。

所有改动在本地开发分支；没有自动推送 GitHub、创建线上发布或改动你的账号安全设置。
