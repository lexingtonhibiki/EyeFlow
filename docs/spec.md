# EyeFlow — 规格文档

## 1. 背景

### 1.1 问题描述
长时间面对屏幕工作/游戏，用户容易忘记休息眼睛，导致视疲劳、干眼症等健康问题。
现有护眼工具要么过于 intrusive（弹窗抢焦点、打断游戏），要么配置复杂违背极简原则。
需要一个能感知上下文、不打扰、恰到好处的护眼提醒工具。

### 1.2 现状分析
用户（Ksir）之前设计过类似工具但效果不好，核心原因：
- 游戏全屏时弹窗抢夺焦点，破坏体验
- 心流状态下突然打断，反而降低效率
- 提示音容易被游戏音效淹没
- 缺乏上下文感知能力

### 1.3 主要使用场景
- **日常桌面使用**：浏览、看视频、写文档
- **编程心流**：长时间专注编码，键盘高频输入
- **全屏游戏**：独占全屏模式，不可被弹窗打断
- **短暂离开**：用户不在电脑前

## 2. 目标

### 2.1 目标
- 在合适的时间，用合适的方式提醒用户护眼
- 提醒后用户需要看远 25 秒
- 零配置开箱即用，参数可配而非必须配
- 系统资源占用极低，不影响主任务

### 2.2 非目标
- 不做视力检测
- 不做眼保健操指导
- 不做使用时长统计大屏
- 不做跨平台（首发仅 Windows）

## 3. 需求

### 3.1 功能性需求
| ID | 需求 | 说明 |
|----|------|------|
| F1 | 定时提醒 | 加权随机间隔，默认 10~18 分钟，提醒护眼 25 秒 |
| F2 | 上下文感知 | 根据用户状态（桌面/心流/游戏/离开）切换提醒方式 |
| F3 | 多模式提醒 | 系统通知 + 提示音（游戏场景仅提示音） |
| F4 | 心流延迟 | 键盘高频输入时延后提醒，等停歇再触发 |
| F5 | 游戏免打扰 | 检测全屏独占模式，不弹窗、仅音效提醒 |
| F6 | 离开检测 | 无输入超时不提醒，重置计时器 |
| F7 | 配置界面 | 主窗口可视化配置所有参数 |
| F8 | 系统托盘 | 常驻托盘图标，快捷开关 |
| F9 | 开机自启 | 安装后默认开机启动 |

### 3.2 非功能性需求
| ID | 需求 | 说明 |
|----|------|------|
| N1 | 内存占用 | < 30MB 常驻 |
| N2 | CPU 占用 | 空闲时 ≈ 0%，检查时 < 1% |
| N3 | 启动速度 | 双击后 < 1 秒托盘出现 |
| N4 | 音频穿透 | 提示音频率设计在 1.5kHz~2.5kHz 谐波区，穿透游戏音效 |
| N5 | 打包体积 | < 10MB |

## 4. 设计方案

### 4.1 方案概览

**核心思路：** 一个纯 Rust 编写的 Windows 系统托盘常驻工具，不使用 WebView。99% 的时间以无窗口状态运行，仅在用户打开设置时弹出原生配置窗口。

**为什么不选 Tauri：** EyeFlow 大部分时间处于无窗口状态，Tauri 即使隐藏窗口也会驻留 WebView2 进程（40-80MB 内存）。纯 Rust 二进制可做到 <5MB 常驻。

**技术栈：**

| 层级 | 选型 | 理由 |
|------|------|------|
| 语言 | Rust stable | 已定 |
| GUI | egui + eframe | 纯 Rust 即时模式 GUI，无 webview 依赖 |
| 系统托盘 | tray-icon (v0.24) | Tauri 组织维护，事件模型清晰 |
| 配置存储 | serde + toml | 简单配置无需复杂序列化 |
| 音频 | rodio | 轻量，代码生成提示音，无需 WAV 文件 |
| 全局快捷键 | global-hotkey | Tauri 组织维护，一键注册热键 |
| Windows API | windows-rs | 全屏检测、键盘钩子、空闲检测、自启 |
| 打包 | NSIS | 安装 + 卸载，清理：exe、config、注册表 RUN 键、卸载程序自身 |

### 4.2 核心模块设计

#### 4.2.1 上下文状态机

EyeFlow 的核心是一个四状态机，根据用户行为自动切换：

```
         ┌──────────────────┐
         │                  │
         │    DESKTOP       │ ←── 默认状态，系统通知 + 提示音
         │                  │
         └───┬───┬───┬─────┘
             │   │   │
     键盘活跃 │   │   │ 全屏检测
             ▼   │   ▼
     ┌──────────┐│  ┌──────────┐
     │  FLOW    ││  │  GAMING  │
     │(心流)    ││  │(游戏)    │
     │延后提醒  ││  │仅提示音  │
     └──────────┘│  └──────────┘
                 │
         空闲超时 │
                 ▼
          ┌──────────┐
          │  AWAY    │
          │(离开)    │
          │重置计时器│
          └──────────┘
```

| 状态 | 检测条件 | 提醒行为 |
|------|---------|---------|
| DESKTOP | 非全屏 + 低键盘活动 | 系统通知 + 提示音，弹 25s 护眼界面 |
| FLOW | 30 秒内按键 > 10 次 | 暂停计时器，最后按键后 8 秒停歇才触发 |
| GAMING | 前台窗口尺寸 = 显示器尺寸 | 仅提示音，不弹窗不抢焦点 |
| AWAY | 无输入超过 3 分钟 | 重置计时器，回来后从零开始 |

#### 4.2.2 事件循环架构

所有组件共享一个单线程事件循环，避免多线程竞争：

```
主线程事件循环:
  ├── Windows 消息 (键盘钩子回调、全屏检测定时器)
  ├── tray-icon 事件 (右键菜单点击、图标双击)
  ├── 定时器事件 (提醒间隔、加权随机调度)
  ├── global-hotkey 事件 (静音开关)
  └── eframe 窗口 (仅在用户打开设置时创建)
```

#### 4.2.3 提醒音设计

提示音使用 **1.5kHz→2.5kHz 上行频率扫描 + 谐波叠加**，持续约 500ms。这个频段高于多数游戏音效（枪声 200-800Hz、爆炸低频、音乐中频），人耳天然能从游戏声中分离出来。音量跟随系统主音量按比例放大。

rodio 可动态生成此波形，不需要额外 WAV 文件。

### 4.3 关键实现决策

| 决策 | 方案 | 替代方案 |
|------|------|---------|
| 全屏检测 | GetForegroundWindow + 窗口尺寸对比 | DXGI（仅限 DirectX） |
| 键盘钩子 | SetWindowsHookEx WH_KEYBOARD_LL（无需管理员权限，监控全部按键） | GetAsyncKeyState 轮询（漏键 + CPU 开销） |
| 空闲检测 | GetLastInputInfo | 已有 20 年验证的 Win32 API |
| 开机自启 | 注册表 HKCU\Run | Task Scheduler（过度设计） |
| 配置存储 | TOML 文件，位于 %APPDATA%/eyeflow/config.toml | JSON / YAML |
| 提示音生成 | 编译期 build.rs 生成音频样本数据，嵌入二进制 | 运行时 rodio Source trait 动态生成 |
| 卸载清理 | NSIS uninstaller：删除 exe + config(.toml) + 注册表 RUN 键 + 卸载程序自身注册 | 手动删除 |

### 4.4 项目结构

```
eyeflow/
├── Cargo.toml
├── src/
│   ├── main.rs              # 入口 + 事件循环
│   ├── tray.rs               # 系统托盘管理
│   ├── reminder.rs            # 提醒调度器（加权随机）
│   ├── state.rs               # 上下文状态机
│   ├── detector.rs            # 全屏检测 + 键盘钩子 + 空闲检测
│   ├── audio.rs               # 音频播放（rodio）
│   ├── config.rs              # 配置读写（serde + toml）
│   └── ui.rs                  # 设置窗口（egui）
├── sounds/                    # 备选提示音 WAV 文件
└── installer/                 # NSIS 安装脚本
```

### 4.5 MVP 范围

第一版实现：
- [x] 系统托盘常驻 + 右键菜单
- [x] 上下文状态机（DESKTOP / FLOW / GAMING / AWAY）
- [x] 加权随机定时提醒
- [x] 系统通知 + rodio 提示音
- [x] 游戏全屏检测（仅提示音）
- [x] 心流检测（键盘钩子）
- [x] 空闲检测（重置计时器）
- [x] 配置窗口（egui），覆盖全部配置项
- [x] 全局快捷键（一键静音）
- [x] 开机自启

非 MVP（后续版本）：
- 护眼 25s 倒计时浮窗动画
- 统计面板（今日提醒次数、护眼总时长）
- 自定义提示音文件
- 暗色/亮色主题
