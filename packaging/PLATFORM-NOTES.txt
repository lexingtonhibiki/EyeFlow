EyeFlow desktop platform support

The reminder core is shared, but platform capabilities are not identical.
Packaging alone does not prove GUI, audio, tray or reminder correctness.

Windows: Windows 10/11 x64. Installer and executable are unsigned; Windows may
warn or prevent launch. Do not disable system security protections.

Linux: Ubuntu 24.04 amd64 DEB. GNOME/KDE X11 automatic reminders require
confirmed idle, lock and fullscreen observations. Unknown/stale observations
pause automatic reminders. Wayland automatic idle monitoring and native global
hotkeys are not implemented. Basic settings, manual rest and quit remain
available through the visible main window even without a working tray.
System Noto CJK fonts are a package dependency, not bundled font copies.

macOS: macOS 15.0 or newer; separate Apple Silicon (arm64) and Intel (x86_64)
builds. Real idle sensing is available, but reliable lock/fullscreen sensing
is unsupported. Automatic reminders pause by default. Explicit compatibility
reminders opt-in accepts possible interruption during lock/fullscreen; it still
requires fresh real idle data and never bypasses failed or missing observations.
The app/DMG is NOT Developer ID signed or notarized. An ad-hoc binary signature
is not Developer ID signing. Gatekeeper may prevent launch. Do not disable
system security protections. Installed system CJK fonts are read locally,
never copied into this app or disk image.

Linux/macOS automatic startup is not implemented; its setting is disabled.
Packaging does not add a startup service or change system permissions.
Audio device switching and popup exit require platform-specific validation;
CI checks do not imply complete user-hardware acceptance on every desktop.

Linux files: /usr/bin/eyeflow; /usr/share/applications/eyeflow.desktop;
/usr/share/icons/hicolor/256x256/apps/eyeflow.png; /usr/share/doc/eyeflow/.
Package-manager removal removes installed files but keeps user config in
$XDG_CONFIG_HOME/eyeflow or ~/.config/eyeflow.
macOS: drag EyeFlow.app to Applications; deleting the app keeps user settings
in ~/Library/Application Support/eyeflow.
